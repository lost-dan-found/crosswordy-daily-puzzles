# crosswordy-daily-puzzles

Static daily crossword puzzle data for the [Crosswordy](https://crosswordy.dev) app, hosted via
GitHub Pages. Generated by [crosswordy-daily-generator](https://github.com/lost-dan-found/crosswordy-daily-generator),
which keeps it stocked about 90 days ahead — nothing in this repo is hand-edited. Future dates are
here on purpose: the app decides which date is today (the player's local date) and never offers
one before its day.

## Layout

```
daily/YYYY-MM-DD/5.json
daily/YYYY-MM-DD/7.json
daily/YYYY-MM-DD/10.json
```

Each file is a solved puzzle: grid solution, slot metadata (direction/position/length/clue
number), and clues per word.

- `dates.json` — every published date, future included. What the app reads.
- `index.json` — past dates only (New York). For older app builds; don't add future dates to it.

## Fetching

A given day's 5×5 is available at:

```
https://daily.crosswordy.app/daily/2026-07-30/5.json
```
